# 객체 지향 메모리 (Object-Oriented Memory)

**객체 지향 메모리(Object-Oriented Memory)** 또는 **객체 중심 메모리(Object-Centric Memory)**는 인공지능 에이전트(예: 로봇)가 주변 환경의 개별적인 객체(object)에 대한 정보를 구조화하고, 저장하며, 추론할 수 있도록 하는 계산적 프레임워크를 의미합니다. 이는 단순히 장면 전체를 하나의 벡터로 압축하는 것이 아니라, 장면을 구성하는 여러 객체 각각에 대한 표현(representation)을 독립적으로 유지하고 업데이트하는 방식입니다.

## 핵심 아이디어

- **분리된 표현 (Disentangled Representation)**: 각 객체는 다른 객체와 분리된 자신만의 상태(state), 속성(attribute), 위치(pose) 등의 정보를 가집니다. 이를 통해 모델은 특정 객체에 더 집중하고 그 변화를 추적하기 용이해집니다.
- **지속성 (Persistence)**: 객체 지향 메모리는 시간에 따라 관찰되는 객체의 정보를 지속적으로 유지하고 업데이트합니다. 이를 통해 객체가 잠시 시야에서 사라졌다가 다시 나타나는 **가려짐(occlusion)** 상황에서도 동일한 객체임을 인식(re-identification)하고 상태를 추정할 수 있습니다.
- **관계 추론 (Relational Reasoning)**: 개별 객체에 대한 표현이 존재하므로, 객체들 사이의 상호작용이나 관계(예: "A 객체가 B 객체 위에 있다")를 명시적으로 모델링하고 추론하는 데 유리합니다.

## 주요 접근 방식

객체 지향 메모리는 다양한 아키텍처를 통해 구현될 수 있습니다.

- **명시적 메모리 모듈 (Explicit Memory Modules)**: 외부 메모리(external memory)나 키-값(key-value) 저장소와 같은 구조를 사용하여 각 객체의 정보를 명시적으로 저장하고 관리합니다.
- **어텐션 메커니즘 (Attention Mechanisms)**: 트랜스포머(Transformer)와 같은 어텐션 기반 모델을 사용하여 객체 간의 관계를 학습하고, 특정 객체에 대한 정보를 선택적으로 읽고 쓸 수 있습니다.
- **그래프 신경망 (Graph Neural Networks, GNNs)**: 객체를 노드(node)로, 객체 간의 관계를 엣지(edge)로 표현하는 그래프 구조를 통해 장면을 모델링합니다.

# 2분 컷(1차 선별)
- [ ] Figure 1 / pipeline 확인
- [ ] Contributions 3줄 확인
- [ ] Assumptions 확인(현실성)
- [ ] Evaluation protocol 확인(사건 중심인지)
- [ ] Ablation 확인(모듈 기여가 있는지)
- 판정: ✅ Keep / ❌ Drop / 🔁 Later

# 10분 컷(2차 추출)
- [ ] Paper Template 채우기(요약 금지)
- [ ] Failure mode 1개 이상 기록
- [ ] Decision Log(D1~D3) 영향 여부 표시

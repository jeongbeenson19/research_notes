# Observation-Centric Momentum (OCM)

**Observation-Centric Momentum (OCM)**, 우리말로 '관측 중심 운동량'은 [[OC-SORT]] 논문에서 제안된 핵심 구성 요소 중 하나입니다. 기존 [[SORT]]와 같은 추적기에서 사용하는 [[Kalman Filter]]의 선형 등속도(linear constant velocity) 모델 가정이 야기하는 한계를 보완하기 위해 설계되었습니다.

OCM의 핵심은 필터의 **예측(prediction) 상태**가 아닌, 실제 **관측(observation)된 데이터**를 기반으로 객체의 운동량, 즉 움직임 방향을 추정하고 이를 데이터 연관(data association)에 활용하는 것입니다.

## 핵심 아이디어: 왜 '관측 중심'인가?

기존의 칼만 필터 기반 추적기는 다음과 같은 문제에 직면합니다:

1.  **오차 누적**: 객체가 가려지거나([Occlusion]) 탐지기가 실패하는 동안, 칼만 필터는 오직 예측에만 의존하게 됩니다. 이 예측이 실제 움직임과 다를 경우(예: 비선형적 움직임), 오차는 시간이 지남에 따라 누적됩니다.
2.  **부정확한 연관**: 누적된 오차로 인해 예측된 위치가 실제 객체의 위치와 크게 달라지면, 객체가 다시 나타났을 때 IoU(Intersection over Union) 기반의 연관이 실패하거나 잘못된 객체와 연결될(ID Switch) 위험이 커집니다.

OCM은 이러한 '추정 중심적(estimation-centric)' 접근 방식에서 벗어나, 가장 최근의 신뢰할 수 있는 '관측'을 중심으로 운동량을 재계산합니다. 즉, 필터의 내부 상태 예측이 아닌, **실제로 탐지된 위치들의 변화**를 통해 객체의 움직임 방향을 판단합니다.

## 작동 방식

OCM은 데이터 연관 단계에서 기존의 IoU 또는 마할라노비스 거리(Mahalanobis distance)에 추가적인 비용(cost) 항으로 작용하거나, 연관 방향을 결정하는 데 사용됩니다.

1.  **방향성 IoU (Directional IoU)**:
    - OCM은 최근 관측된 궤적의 방향성을 계산합니다.
    - 현재 프레임의 탐지(detection)와 예측된 트랙(track)을 연결할 때, 단순히 IoU 값만 보는 것이 아니라, **트랙의 운동량 방향과 일치하는 탐지**에 더 높은 우선순위를 부여합니다.
    - 예를 들어, 왼쪽으로 움직이던 트랙이 있다면, 그 트랙의 예측 위치보다 약간 왼쪽에 나타난 탐지가 오른쪽에 나타난 탐지보다 더 높은 연관 점수를 받게 됩니다.

2.  **연관 비용 행렬 수정**:
    - OCM으로 계산된 방향성 불일치(directional disagreement)를 연관 비용(cost matrix)에 페널티로 추가할 수 있습니다.
    - 이를 통해 [[Hungarian Algorithm]]이 최적의 매칭을 찾을 때 움직임의 연속성을 더 중요하게 고려하게 됩니다.

## 주요 장점

-   **ID 스위치 감소**: 객체들이 서로 교차하거나 가려진 후 다시 나타날 때, 움직임 방향 정보를 통해 올바른 ID를 유지할 확률이 높아집니다.
-   **비선형 움직임에 대한 강건성**: 칼만 필터의 선형 모델 가정이 깨지는 복잡하고 급작스러운 움직임(예: 춤, 스포츠)에 더 잘 대응할 수 있습니다.
-   **간단하고 효율적**: OCM은 복잡한 딥러닝 모델 없이 간단한 계산으로 구현 가능하며, [[SORT]]의 실시간 처리 속도를 유지하는 데 기여합니다.
